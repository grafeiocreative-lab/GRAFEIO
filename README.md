# Grafeio — Landing Page

## Struktura
```
grafeio/
├── index.html        ← celotna stran (HTML + CSS + JS v enem)
├── README.md         ← ta dokument
├── .gitignore
└── DEPLOY.md         ← navodila za deployment
```

## Lokalni ogled
Odpri `index.html` direktno v brskalniku — ni potreben noben strežnik.

## VS Code
1. Odpri mapo v VS Code: `File → Open Folder → grafeio`
2. Priporočena razširitev: **Live Preview** (ms-vscode.live-server)
   - Desni klik na `index.html` → "Open with Live Server"

## Formspree (obrazec)
1. Registracija: https://formspree.io z grafeio.creative@gmail.com
2. New Form → kopiraj ID (npr. `xpwzqdkv`)
3. V `index.html` poišči `YOUR_FORM_ID` in zamenjaj z ID-jem
